# WONDERFUL PRINT

Wonderful Print company website, redesigned from the owner-provided https://printer-ashy.vercel.app/ page on 2026-11-14. The original content is in `dist/index.html`; `experience.css` and `experience.js` add the navy/silver design, animated artwork, scroll reveals, mobile navigation, progress indicator and pointer tilt. Google Fonts remains an external font provider. No original deployment assets are required. Deploy with Vercel using output directory `dist`, framework preset Other, no build command.

Contact information remains the original placeholder. Motion respects prefers-reduced-motion; content stays visible if JavaScript is unavailable. Earlier design assets in `dist` are unreferenced by this page. Browser verification covered desktop, 390px mobile layout, mobile menu open/close and anchor navigation, no mobile horizontal overflow, and reveal activation.
